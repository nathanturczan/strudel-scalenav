# Contributing to strudel-scalenav

Pull requests are welcome! Here's how to contribute:

## Quick PR workflow

1. **Fork this repo** (top-right button on GitHub)
2. **Clone your fork**:
   ```bash
   git clone https://github.com/YOUR-USERNAME/strudel-scalenav
   cd strudel-scalenav
   npm install
   ```
3. **Make your changes**
4. **Test locally**:
   ```bash
   npm run build
   # Then test in the Strudel REPL using your fork's URL
   ```
5. **Commit and push to your fork**:
   ```bash
   git add .
   git commit -m "Description of your changes"
   git push origin main
   ```
6. **Open a PR** on GitHub from your fork to this repo

## What makes a good PR

- **Clear description** of what the bug/issue was and how you fixed it
- **Examples** showing the problem and the solution
- **Test it** in the Strudel REPL before submitting

## Bug reports

If you find a bug:
1. Open an issue with:
   - What you expected to happen
   - What actually happened
   - Minimal code example to reproduce it
2. If you have a fix, submit a PR linking to the issue
